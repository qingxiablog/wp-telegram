## 功能特性

- **纯净无广**：彻底剥离 Pro 升级提示、付费广告及购买横幅，无后门、无多余框架。
- **全中文界面**：原生 Settings API 架构，全中文说明、格式规范、错误提示与操作引导。
- **文章推送引擎**：
  - 支持新文章发布、已有文章更新触发；
  - 智能识别 24 小时内新文章，防止老文章重复推送；
  - 支持单条图文合并 (Caption) 或分开多条发送；
  - 自动将分类转换为 Telegram 话题标签（如 `#科技`）；
  - 支持内联阅读按钮 (Inline URL Button)；
  - 编辑器（古腾堡 / 经典）支持单篇发送开关与独立规则覆盖。
- **邮件转发引擎**：同步捕获 WordPress 系统邮件（注册、评论、重置密码等），按收件人规则秒级推送到指定 Telegram 目标。
- **多途径代理机制**：支持 Cloudflare Worker、Google Apps Script 及 HTTP/SOCKS 本地代理，完美应对网络受限环境。
- **数据平滑接管**：无缝读取旧版文章已发标记，一键导入旧版配置，安全接管未执行的定时延迟任务。

## 环境要求

- **WordPress 版本**：6.6 或更高（推荐 6.6 / 6.7）
- **PHP 版本**：8.0 或更高（兼容 PHP 8.1、8.2、8.3）
- **依赖说明**：安装包已内置全部运行依赖库（`wpsocio/*`），无需安装 Composer 或执行 npm 构建。

## 安装方法

### 后台直接上传安装（推荐）

1. 下载打包完成的 `wptelegram-free-cn-1.0.0.zip`。
2. 登录 WordPress 管理后台，点击 **插件 -> 安装插件 -> 上传插件**。
3. 选择该 ZIP 文件并点击 **现在安装**。
4. 安装完成后，点击 **启用插件**。
5. 导航至后台 **设置 -> Telegram 推送** 开始配置。

## 配置指南

### 1. 基础设置与机器人凭据

1. 打开 Telegram，搜索官方 Bot 创建器：`@BotFather`。
2. 发送 `/newbot` 指令，按照提示输入机器人的显示名称与唯一的用户名（以 `bot` 结尾）。
3. BotFather 会返回一段形如 `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ` 的 **API Token**（机器人令牌）。
4. 将该令牌填入插件后台 **基础设置 -> 机器人令牌 (Bot Token)** 中。
5. 点击 **测试机器人连接 (getMe)**，若连通正常，插件会自动读取并回填机器人用户名。

> **小贴士**：请先在 Telegram 中找到您的机器人并向其发送一条 `/start` 消息，以允许机器人给您发送消息。

---

### 2. 文章自动推送 (P2TG)

- **启用文章自动推送**：总开关，开启后生效。
- **接收频道或群组 (Channels)**：每行填写一个目标。
  - **公开频道/群组**：填写用户名，如 `@my_news_channel`（必须先将机器人添加为管理员，并赋予发帖权限）。
  - **私有群组/频道**：填写纯数字 ID，如 `-1001234567890`。
  - **论坛超级群话题 (Topics)**：使用冒号连接群 ID 与话题 ID，如 `-1001234567890:123`。
  - **识别备注**：可用竖线追加仅在后台可见的备注，如 `-1001234567890 | 交流主群`。
- **自动发送时机**：可勾选“新文章首次发布”和/或“已有文章更新”。
- **允许发送的内容类型**：可选择文章 (post)、页面 (page) 或自定义类型（如产品）。
- **延迟发送**：设置文章发布后等待几分钟再推送（如 `0.5` 为 30 秒，`0` 为立即推送），便于修正临时笔误或等待缩略图生成。

---

### 3. 邮件通知转发 (Notify)

- **启用邮件通知转发**：开启后，站点通过 `wp_mail()` 发出的邮件将自动镜像发送到 Telegram。
- **需要转发的收件邮箱**：输入监控的收件地址，多个用英文逗号分隔。填写 `any` 则转发站点发出的所有系统邮件。默认为网站管理员邮箱。
- **通知接收目标 (Chat IDs)**：填写接收通知的个人或管理群 ID。

---

### 4. 连接代理配置 (Proxy)

若您的主机服务器位于中国大陆等无法直接访问 Telegram API 的网络环境中，请启用代理：

1. **Cloudflare Worker（推荐）**：
   - 在 Cloudflare 上部署官方兼容的反向代理 Worker。
   - 在插件中填入 Worker 的 HTTPS 基础地址，如 `https://my-proxy.workers.dev`。插件请求时会自动拼接 `/bot`。
2. **Google Apps Script**：
   - 部署 Google Apps 转发脚本，将 Web 应用 URL 填入相应字段。
3. **HTTP / SOCKS 本地代理**：
   - 填写代理服务器的 IP/Host、端口、协议（如 `CURLPROXY_SOCKS5`），以及可选的认证账号与密码。

---

### 5. 高级设置 (Advanced)

- **通过图片链接发送文件**：开启（默认）时，Telegram 官方服务器将直接下载图片的公开 URL，极大节省本站服务器流量与内存；若站点处于局域网或有防盗链，可关闭此项采用服务器本地上传。
- **调试日志记录**：可在排查故障时勾选启用“接口日志”或“推送日志”，日志保存在 `wp-content/wptg-logs/` 中并自动脱敏。
- **卸载时清理新版数据**：在后台点击“删除插件”时自动清理本插件数据。

## 消息模板与变量语法

可在后台模板中自由组合以下变量宏：

| 变量宏 | 说明 | 示例 |
| :--- | :--- | :--- |
| `{post_title}` / `{title}` | 文章标题 | `WordPress 6.7 正式发布` |
| `{post_excerpt}` / `{excerpt}` | 文章摘要 | 根据设定长度截取的简介 |
| `{post_content}` / `{content}` | 文章正文全文 | 文章完整主体内容 |
| `{full_url}` | 文章永久链接 | `https://example.com/hello-world` |
| `{short_url}` | 文章短链接 | `https://example.com/?p=123` |
| `{post_author}` / `{author}` | 作者显示名称 | `张三` |
| `{post_date}` / `{post_time}` | 本地发布日期 / 时间 | `2026-10-02` / `09:30` |
| `{post_id}` / `{id}` | 文章 ID | `123` |
| `{categories}` | 文章分类（支持话题标签模式） | `科技` 或 `#科技` |
| `{tags}` | 文章标签 | `#WordPress #PHP` |
| `{terms:taxonomy}` | 自定义分类法项目 | `{terms:product_cat}` |
| `{cf:meta_key}` | 自定义文章字段 (Post Meta) | `{cf:price}` |

### 条件语法 `[if]`

仅当宏对应的值非空时输出某段内容：

```text
[if {macro}][成立时输出的内容][可选：为空时输出的内容]
```

**示例**：
```text
<b>{post_title}</b>

{post_excerpt}

[if {tags}][🏷️ 标签：{tags}
][]🔗 阅读全文：{full_url}
```

## 从原版 WP Telegram 迁移

如果您之前安装并配置过原版 WP Telegram (4.2.15)：

1. **建议流程**：在插件列表先停用原版 WP Telegram，再启用“Telegram 中文免费版”。
2. **导入配置**：进入 **设置 -> Telegram 推送 -> 基础设置**，点击 **导入 / 重新同步旧版配置**。
3. **数据保护**：
   - 插件会自动读取原版的已发送文章记录（`_wptg_p2tg_sent2tg`），**绝不会对旧文章造成重复轰炸**；
   - 原版保存的草稿独立覆盖参数会被无缝继承；
   - 队列中正在等待延迟发送的任务（WP-Cron 或 Action Scheduler）会自动迁移并接管，不会发生漏发；
   - 迁移仅导入并备份数据，绝不会篡改或破坏原版的数据库选项。

## 卸载与数据清理

- **停用插件**：保留所有配置、数据及已发标记，定时延迟任务暂停。
- **删除插件**：
  - 若在“高级设置”中勾选了“卸载时清理新版数据”，系统将自动清理 `wptg_free_cn_options` 及日志目录；
  - 无论是否勾选，**绝不会删除原版 WP Telegram 的配置**，也绝不删除共享的用户绑定信息（`wptelegram_user_id`）。

## 常见问题与技术支持

**Q：为什么点击发布后 Telegram 频道没有收到消息？**
1. 检查“文章推送”设置中的“启用文章自动推送”总开关是否开启。
2. 检查频道接收目标中是否包含了正确的 `@频道名` 或 ID。
3. 确保您的机器人已被加入该频道并提升为**管理员**，且勾选了“发布消息”权限。
4. 若服务器无法访问外网，请进入“连接代理”配置代理。

**Q：消息中的 HTML 格式为什么报错？**
Telegram 仅支持受限的 HTML 标签（如 `<b>`、`<i>`、`<a>`、`<code>`、`<pre>`）。不支持 `<div>`、`<p>`、`<span>` 等容器标签。插件已内置自动 HTML 转换与清洗引擎，建议选择 HTML 解析模式。
